# Safe Account Launchpad

Create a minimal static React + Vite site.

1. Create the folder public/i8ugbeqri/ (put a .gitkeep in it). I will upload files into it through GitHub. Never create, edit or delete anything inside it.

2. The home page '/' shows a centered notice: "Please use an ALT account. Never sign in with your main account." Below it, a "Launch" button that goes to '/i8ugbeqri/launcher/index.html'.

3. No service worker, no PWA plugin, no analytics, and no catch-all rewrite that would block files under /i8ugbeqri/.

4. Connect the project to GitHub. IF you cant ill do it myself ok
